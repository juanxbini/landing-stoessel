# Stoessel Inmobiliaria - Landing Page Modernizado

Landing page moderno para Stoessel Inmobiliaria, desarrollado con React 18, Vite, Tailwind CSS, Framer Motion y Lucide React.

## 🏠 Descripción

Sitio web profesional para inmobiliaria ubicada en Bahía Blanca, Argentina. Ofrece servicios de compra, venta y alquiler de propiedades en Bahía Blanca, Pehuen Co y Monte Hermoso.

## 🚀 Tecnologías Utilizadas

- **React 18** - Framework frontend con hooks modernos
- **Vite** - Build tool ultra rápido para desarrollo
- **Tailwind CSS** - Framework de estilos utility-first
- **Framer Motion** - Animaciones fluidas y motion design
- **Lucide React** - Iconos modernos y consistentes
- **Inter** - Tipografía profesional de Google Fonts

## ✨ Características

- 🎨 Diseño moderno y responsive
- ⚡ Rendimiento optimizado con lazy loading
- 🎭 Animaciones suaves con Framer Motion
- 📱 Totalmente responsive (mobile-first)
- 🎯 Componentes reutilizables
- 🔄 Build optimizado con code splitting
- 🌐 SEO friendly con semántica HTML5

## 🛠️ Instalación

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Build para producción
npm run build

# Previsualizar build de producción
npm run preview
```

## 📁 Estructura del Proyecto

```
src/
├── components/          # Componentes React
│   ├── Navbar.jsx      # Barra de navegación
│   ├── Hero.jsx        # Sección principal
│   ├── ProblemsSection.jsx
│   ├── SolutionSection.jsx
│   ├── HowItWorks.jsx
│   ├── Testimonials.jsx
│   └── CTASection.jsx  # Llamada a la acción y footer
├── App.jsx             # Componente principal
└── index.css           # Estilos con Tailwind CSS
```

## 🎨 Personalización

El proyecto utiliza variables CSS personalizadas en `tailwind.config.js`:

- `primary` - Color principal gris azulado
- `accent` - Color verde petróleo
- `accent-contrast` - Color ámbar
- `text-muted` - Texto secundario
- `bg-light` - Fondo claro
